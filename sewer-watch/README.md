# 💧 영천 하수구 수위 알리미

경상북도 **영천시** 맨홀(하수구)에 설치한 초음파 센서로 수위를 실시간 측정하고,
위험 수위에 가까워지면 **소리·진동·푸시 알림**으로 시민과 담당자에게 알려주는 앱입니다.

## 문제 정의
- 집중호우 때 하수관이 넘치면 맨홀 뚜껑이 솟구치고 도로·지하차도·반지하가 침수됩니다.
- 영천은 금호강을 끼고 있어 시장·역 주변 저지대가 비에 취약합니다.
- 지금은 침수가 **일어난 뒤에야** 신고로 알게 됩니다 → **넘치기 전에** 알려주자!

## 주요 기능
| 기능 | 설명 |
|---|---|
| 실시간 대시보드 | 영천 시내 8개 지점 수위, 지도 마커 색상, 위험한 순 정렬 |
| 4단계 경보 | 맨홀 깊이 대비 **안전 <50% · 주의 50% · 경고 70% · 위험 85%** |
| 위험 도달 예측 | 최근 수위 상승 속도(cm/분)로 "위험까지 약 N분" 계산 |
| 알림 | 화면 배너·토스트, 경고음, 휴대폰 진동, 브라우저 푸시 알림 |
| 오경보 방지 | 경계값 근처에서 알림 반복되지 않도록 히스테리시스(3%) 적용 |
| 현장 경보 | 통신이 끊겨도 센서 노드 자체 부저·LED 경보 |
| 행동요령 | 대피 요령, 119·영천시청 바로 전화 |
| 앱 설치(PWA) | 휴대폰 홈 화면에 추가해서 앱처럼 사용 |

## 구성
```
sewer-watch/
├─ public/            웹 앱 (휴대폰/PC 브라우저)
│  ├─ index.html, style.css, app.js
│  ├─ sensors.js      ← 센서 지점·기준값 설정
│  └─ sw.js, manifest.webmanifest, icon.svg  (PWA)
├─ server.js          센서 데이터 수신 서버 (Node.js, 외부 패키지 없음)
├─ tools/fake-sensor.js  하드웨어 없이 실제 센서 흉내 (발표 시연용)
├─ firmware/sewer_sensor/sewer_sensor.ino  ESP32 + JSN-SR04T 센서 코드
└─ test/              서버 API 테스트
```

## 실행 방법
Node.js 18 이상 필요.

```bash
cd sewer-watch
npm start                 # http://localhost:3000 접속
```
- 서버 없이 `public/index.html`만 열어도 **데모 모드**(시뮬레이션)로 동작합니다.
- 서버로 열면 배지가 **라이브**로 바뀌고, 실제 센서 값이 들어온 지점은 `📡 실측`으로 표시됩니다.
  (값이 없는 지점은 시뮬레이션으로 채움)
- 같은 Wi‑Fi의 휴대폰에서 `http://<PC IP>:3000` 으로 접속하면 됩니다.

### 발표 시연 순서 (추천)
1. `npm start` 후 화면을 띄우고 **🔔 알림 켜기** 클릭
2. 다른 터미널에서 `npm run fake-sensor` → "완산동 지하차도"가 실측으로 차오르며 경보 발생
3. **⛈ 집중호우 시나리오** 버튼 → 비가 85mm/h까지 늘며 저지대부터 주의→경고→위험 순으로 알림
4. 지점을 눌러 수위 그래프와 "위험까지 약 N분" 예측 보여주기

> 지도(OpenStreetMap)와 그래프(Chart.js)는 인터넷이 필요합니다. 없어도 목록·알림은 동작합니다.
> 브라우저 푸시 알림은 `localhost` 또는 HTTPS에서만 동작합니다.

## 하드웨어 (센서 노드)
- **ESP32** + **JSN-SR04T 방수 초음파 센서** (+ 부저, LED)
- 맨홀 뚜껑 아래에 센서를 아래로 향하게 설치 → 수면까지 거리를 측정
- **수위 = 맨홀 깊이 − 측정 거리**, 5회 측정 중앙값으로 노이즈 제거
- 평상시 10초, 위험 시 3초 간격으로 `POST /api/readings` 전송
- `firmware/sewer_sensor/sewer_sensor.ino` 상단의 Wi‑Fi, 서버 IP, `SENSOR_ID`, `DEPTH_CM` 수정 후 업로드

## API
| 메서드 | 경로 | 내용 |
|---|---|---|
| GET | `/api/sensors` | 최신 실측값 + 강우량 |
| POST | `/api/readings` | `{"id":"YC-01","distance_cm":120}` 또는 `{"id":"YC-01","level_cm":60}` |
| POST | `/api/rain` | `{"rain":45}` 강우량(mm/h) 설정 → 모든 화면에 반영 |
| GET | `/api/stream` | 실시간 이벤트(SSE) |

환경변수 `API_KEY`를 설정하면 센서 업로드 시 `x-api-key` 헤더가 필요합니다.

## 확장 아이디어
- 기상청 단기예보 API로 실제 영천 강우량·예보 연동 → 예측 정확도 향상
- 영천시 재난안전문자·카카오 알림톡 연동
- 위험 단계 시 지하차도 진입 차단 전광판 자동 연동
- 센서 배터리·통신 상태 모니터링, LoRa/NB-IoT 통신

※ 센서 위치 좌표는 데모용 예시이며 실제 설치 위치가 아닙니다.
